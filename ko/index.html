Zero-Touch SSL Matrix

상용 EV/OV/DV + 무료 와일드카드 SSL 자동화 파이프라인

단일 벤더 종속 탈피. 상용 인증서 및 무료 와일드카드 ACME 인증서의 원클릭 발급, 공인 IP 인증서, 무중단 자동 갱신 및 전체 분배를 지원합니다.

STEP 01

상용 CA 및 ACME 자동 발급

Let's Encrypt / ZeroSSL / GTS 무료 와일드카드 발급 지원 및 DigiCert / Sectigo / GlobalSign 상용 인증서의 DNS 챌린지를 무중단 지원합니다.

STEP 02

공인 IP 및 와일드카드 인증서

*.example.com 도메인은 물론, 서버 공인 IP 주소에 대한 규격 SSL 인증서 발급을 단독 지원하여 도메인 수 제한 없이 사용 가능합니다.

STEP 03

주기적 검사 및 무인 자동 갱신

백그라운드 엔진이 인증서 체인과 만료일을 매일 전수 점검하여, 만료 30일 전 자동으로 무인 갱신을 실행해 장애를 사전 차단합니다.

STEP 04

다중 노드 배포 및 무중단 리로드

SSL Agent가 Nginx / HAProxy를 안전하게 Reload하며, K8s Ingress Secret 자동 동기화 및 주요 클라우드 CDN 배포를 지원합니다.

자주 묻는 질문 (FAQ)

1. 어떤 결제 방식을 지원하나요?

+
주요 가상자산(USDT / USDC) 온라인 온체인 결제를 지원합니다. TRON 네트워크는 지원하지 않습니다.

2. 어떻게 글로벌 수십 개 DNS 제공업체와 완벽히 호환되나요?

+
Hermes는 각 클라우드 제공업체의 상이한 API를 표준화된 데이터 모델로 변환하는 산업용 어댑터 계층을 내장하고 있습니다. 라우팅 정책을 한 번만 정의하면 Cloudflare, AWS Route53 등에 자동 동기화되어 벤더 종속을 완벽히 탈피할 수 있습니다.

3. '당신의 제품이 곧 당신의 탐지 매트릭스'는 어떤 의미인가요?

+
기존 데이터센터 프로브는 비용이 비쌀 뿐 아니라 실제 유저들의 가정용 초고속 인터넷이나 모바일 통신 품질을 정확히 대변하지 못합니다. Hermes Rust SDK를 클라이언트 앱에 임베드하면 전 세계 실사용자 디바이스가 가벼운 분산 샘플링에 참여하여 이상 징후를 밀리초 단위로 파악하고 우회합니다.

4. 소스코드 구매 후 사내에서 무제한 배포가 가능한가요?

+
네, 가능합니다. 10,000 USDT(정가 29,999 USDT) 상용 라이선스를 구매하시면 백엔드, 프론트엔드, CoreDNS 플러그인, 에이전트, Rust SDK를 포함한 전체 소스코드가 제공되며 도메인 수나 트래픽 제한 없이 영구 사용할 수 있습니다.
